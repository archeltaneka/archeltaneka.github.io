# Portfolio fonts

Antonio 700 and Inter 400/500/600/700 are self-hosted from Google Fonts (https://fonts.google.com/), licensed under the accompanying SIL Open Font License files.

Fetched from the Google Fonts CSS endpoint for these families and weights, then subset to Latin, punctuation, and the right-arrow character and compressed to WOFF2 with fontTools. Chinese name glyphs use the platform's Chinese sans-serif fallback. No runtime font service request is required.
